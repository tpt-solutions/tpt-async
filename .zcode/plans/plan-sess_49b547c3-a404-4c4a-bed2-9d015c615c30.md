## Phase 1 — Soundness fixes

**Timer redesign** (`tpt-async-timer`), root fix for the unusable-borrow bug:
- Change `TimerWheel` methods (`tick`, `insert`, `remove`, `now`) to `&self` with a `spin::Mutex`-protected interior (no_std-safe). `Sleep`/`Timeout` then hold shared `&TimerWheel` — no exclusive-borrow deadlock, no `*mut`, `Send` falls out of `TimerWheel: Sync`.
- Collect due entries under lock, drop lock, then wake (fixes re-entrancy deadlock hazard).
- Make `TimerEntry` `!Send + !Sync` (`PhantomData<*mut ()>`) and stop exporting it from the prelude; `Sleep` owns its entry (kills the drop-while-registered UB surface).
- `Interval` rewritten to own its `Sleep` inline (no more `Pin<&mut Sleep>` + second `&mut wheel`); remove the unsound `unsafe impl Send`. Add `MissedTickBehavior` (Skip/Burst/Delay).
- Add `Duration` API: `Sleep::for_duration(dur)` via a `Clock` trait (std `StdClock` wired in; fixed-rate `FakeClock` for tests); `advance_to`/`tick_n` batched catch-up; fix boundary-skew off-by-one and `pow` overflow (saturating); compile-time const asserts (`SLOTS >= 2`).
- std convenience: lazily-initialized global driver thread + `sleep(dur)` / `timeout(dur, fut)` free functions — the spec's "just works" story.

**Executor** (`tpt-async-executor`):
- Wakers: `Arc` + `AtomicBool` + `Mutex<VecDeque>` instead of `Rc`/`RefCell` — cross-thread wake becomes sound; document single-threaded *polling*.
- `block_on`: replace the stall panic with a real park (`Condvar`/`park_timeout`) integrated with the std timer driver; add a `completed` flag so finished tasks aren't re-polled and duplicate wakes are coalesced.
- Add `prelude` module; add `JoinHandle::cancel()/detach()` in core + documented fused-poll semantics.

**Macros + facade**:
- `#[tpt_async::main]` emits a facade-resolvable hidden path (`tpt_async::__private::LocalExecutor`); facade gains `#[doc(hidden)] pub use tpt_async_executor as __private;`; `macros` feature implies `executor`; handle `Result` returns via `Termination` (exit code / panic on Err) instead of silently discarding.
- Core: closure-based `waker_fn` behind `alloc`; fix wrong `!Unpin`/transmute comments (L3–L6).

**TLS** (`tpt-net-tls`):
- `poll_write` returns `Pending` (with stored waker woken on next poll) instead of lying success — kills the silent-deadlock; same waker-awareness in flush path.
- `rustls_config()` returns `Result` (no `.expect`), reports cert parse failures, errors on empty trust store; add PEM cert/key loaders using the currently-unused `rustls-pemfile`.
- Typed errors: preserve `rustls::Error` in a `TlsError::Rustls` variant; remove dead `HandshakeNotComplete` or construct it; optional connect/accept timeout parameter wired to the timer crate.

## Phase 2 — Facade integration + adoption package

1. **Facade**: add `io` feature (re-export `tpt-async-io` prelude incl. new `AsyncReadExt`/`AsyncWriteExt`), optional `tls`/`http`/`ws` features re-exporting net preludes; un-gate `Duration` (it's `core`).
2. **Ready-made `Spawn` impls** behind facade features `spawn-tokio` / `spawn-smol` (maps their JoinHandle to ours) — "bring your own executor" becomes zero-boilerplate; big adoption unlock.
3. **Examples** (new `examples/` dir; desktop one is a workspace member, embedded/wasm excluded sub-workspaces so CI stays green):
   - `examples/desktop`: TCP echo + TLS GET (`cargo run -p desktop-examples`).
   - `examples/embedded`: Cortex-M `thumbv7em` no_std bin (heapless wheel + no-alloc spawn, systick-driven).
   - `examples/wasm`: `wasm-bindgen` demo with a `performance.now()` clock.
   - `templates/tpt-app/`: cargo-generate template (cargo-generate.toml, desktop/embedded/wasm flavor flags, pre-wired deps, README).
4. **Benches** (fills 3 dead criterion dev-deps): timer wheel insert/remove/tick, executor spawn+block_on vs `LocalSet`, `ReadBuf` throughput.
5. **Tests for the untested**: timer Sleep/Timeout/Interval driving + boundary math; executor waker-reuse/cancel-on-drop/cross-thread wake; `ReadBuf` units; io adapter round-trips (tokio dev-dep finally used); macros trybuild UI tests + a facade consumer test (would have caught the E0433); TLS shutdown + `tls12` feature test.

## Phase 3 — Implement tpt-net-http (HTTP/1.1) and tpt-net-ws (RFC 6455)

- **http**: zero-copy header parser over `ReadBuf` slices; request/response types; chunked transfer decode; Content-Length handling (strict, dual-length → reject: no smuggling surface); client (`HttpClient` builder: `.tls()`, `.timeout()` → timer wheel, `.send()`, redirects off by default); server (RPITIT handler trait, keep-alive). HTTP/2 deferred (feature removed in Phase 0).
- **ws**: handshake over tpt-net-http (client + server, correct `Sec-WebSocket-Accept` via RustCrypto `sha1`), frame codec with bounds checks + 16 MiB cap, masking, fragmentation, ping/pong keepalive on the timer, close-code validation; permessage-deflate deferred (feature removed in Phase 0).
- **Integration tests**: in-memory duplex echo (plain + TLS), HTTP client↔local server, WS echo/fragmentation/close. Autobahn suite noted as follow-up in todo.md.
- **README/spec alignment**: rewrite README quickstart to a compiling, doc-tested example; update crate table to actual status.

## Phase 4 — Automation & publish readiness

- CI additions: coverage job (cargo-llvm-cov), `cargo-semver-checks` on PRs, `cargo publish --dry-run` step, tag-triggered release workflow publishing in dependency order (core → timer → macros → executor → io → tls → http → ws → facade).
- Fuzz targets (`fuzz/`, excluded workspace): timer tick-advance, HTTP parser, WS frame decoder.
- Verify crates.io dry-run per crate (license/fields now inherited), docs.rs metadata already correct.
