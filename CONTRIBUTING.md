# Contributing to tpt-async

Thank you for your interest in tpt-async!

## Issues only

Contributions to tpt-async are accepted as issues only. Pull requests are not
being accepted.

- **Bugs:** open an issue with the bug report template. Include the crate,
  the version, the target platform, and a minimal reproduction.
- **Feature requests:** open an issue with the feature request template.
  Describe the use case first, then the proposed API if you have one.
- **Questions:** open an issue rather than a pull request.

Pull requests opened against this repository will not be reviewed or merged.
